# 动画、原图匹配与前后台联调报告

## 结论

- 引导页从素材加载态进入 ready/animating 状态，动画结束帧的 Logo、角色、信封、报告牌、爱心和滑动提示与 `docs/input/design/home-page-v2/guide-final-reference-v2.jpg` 保持同一构图关系。
- 手机比例下页面宽高完整占满视口，页面本身没有横向或纵向文档滚动；引导完成后点击“进入档案”可切换到 `/reports`。
- 后台卡片标题编辑会即时显示在右侧 H5 预览中；保存已发布卡片后，正式前台分类页能读到新标题。
- 联调测试使用“核心营养含量（联调验证）”，前台确认出现后已恢复为“核心营养含量”，没有保留测试文案。
- 修复了一个实际阻断：新增资料的必填字段原先嵌在卡片编辑表单中，导致没有新增资料时也无法保存卡片，且界面没有错误提示。现在卡片编辑与新增资料为两个独立表单。
- 后台危险操作改为默认收起的“更多操作”，降低误触和视觉干扰。

## 走查步骤

1. 引导页素材加载：健康。初始状态为 `is-loading`，素材准备后进入 `is-ready is-animating`。
2. 动画结束帧：健康。主要视觉元素与原图的相对位置、层级和比例一致。
3. 页面切换：健康。用户主动点击后进入档案首页，不会在动画结束后自动跳转。
4. 后台选择卡片：健康。内容树可直接选择分类、卡片和资料。
5. 后台编辑预览：健康。输入卡片标题时右侧分类详情即时更新，并提示存在未保存修改。
6. 保存并发布：修复后健康。一次点击“保存已发布卡片”即可保存，出现成功状态。
7. 正式前台同步：健康。刷新 `/reports/inspection-projects` 后出现新标题。
8. 数据恢复：健康。测试标题恢复后，前台不再出现联调标记。

## 视觉边界

- 原始插画、固定文案、动画层级和时序继续由前端版本管理，后台不允许破坏画面构图。
- 后台适合调整分类名称、卡片名称、运营说明、排序、发布状态和报告资料。
- 分类详情中的部分原图固定说明文案来自前端配置；后台“卡片说明”目前不会替换这些固定设计文案。若要开放该字段，需要先确认哪些原图文字允许运营人员修改。
- 本轮内置浏览器在显式手机视口截图时会生成重复平铺画面；DOM 实测视口为 750×1624、页面滚动尺寸也是 750×1624，因此平铺属于截图工具显示问题，不是页面重复渲染。
