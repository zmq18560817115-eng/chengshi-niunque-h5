# 引导标识与首页部件微调

- 引导页下方标识保留原先 900ms 的渐显上移入场，随后每 1800ms 上下跳动一次，位移为标识自身高度的 14%。横竖屏共用规则；减少动态效果模式保留静态展示。
- 紫色下滑条改由引导过渡层紧接第二组批次卡片播放，800ms 入场曲线、最终位置及自然滚动保持不变。页面交接时按统一开始时间续播，避免等待深层素材造成延迟，也避免完整重播。
- 两张纸片从约半露出的状态继续上移和渐显。两张原始图片已有不同程度被文件夹遮挡，因此分别使用自身高度 22% 和 18% 的起始下移量、0.5 的起始透明度；原有 672ms 时长、滚动触发、层叠顺序、最终位置和返回时保持终态的行为不变。

未修改后台、文案、报告数据、源素材文件或其他交互。

验证：lint、typecheck、306 项测试、Prisma 校验和生产构建。浏览器脚本分别检查标识进入及循环跳动、第二组和紫色条的时间衔接、纸片起始位移与最终坐标，并覆盖 Chromium / WebKit、长短竖屏、横屏及减少动态效果模式。证据在忽略目录 `artifacts/guide-hint-entry-qa/`、`artifacts/ribbon-entry-qa/` 和 `artifacts/folder-paper-qa/`。
