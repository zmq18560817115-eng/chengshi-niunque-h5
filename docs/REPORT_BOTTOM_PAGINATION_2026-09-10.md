# 图片报告底部翻页（2026-09-10）

根据用户提供的安全底线报告截图，将通用图片报告组件的翻页控件从图片上方移至图片下方。多页时显示“点击翻页，查看下一份报告”，保留上一页、页码和下一页，并以当前分类配色突出下一页。最后一页显示结束提示，单页报告不显示翻页控件。

从底部切换图片后恢复 100% 缩放，将阅读位置和键盘焦点移至当前报告标题。图片随后加载完成不会再次抢占滚动位置；图片失败时仍可通过底部控件切换。原有图片来源、缩放及拖动交互保持原样。

验证：

- 图片报告组件 3 项单元测试通过，覆盖切换定位、延迟加载、错误恢复和原有缩放操作。
- 实际 Next 页面和通用组件验证：Chromium 320×568、375×812、393×780、430×932；WebKit 375×812、844×390，全部通过。
- 浏览器检查底部位置、无横向溢出、长短图切换、延迟响应、末页状态、加载失败后返回以及缩放后翻页复位。
- `pnpm lint`、`pnpm typecheck`、`pnpm prisma:validate`、`pnpm build` 通过。
- `pnpm test`：306 通过、11 失败、6 跳过。失败为本机 `localhost:5432` 数据库不可用及关联健康检查，与此前环境限制一致。

浏览器使用本地固定内容和拦截图片请求，不写入数据库或存储。截图及日志位于忽略目录 `artifacts/report-pagination-bottom-2026-09-10/`，报告图片不纳入仓库。
