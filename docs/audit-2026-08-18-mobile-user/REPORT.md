## UX / 可访问性观察

- 主要热点具有按钮语义、可访问名称及键盘焦点样式，移动端触控区域不小于 44px。
- 分类页正文和主按钮在 375px 宽度下仍可读。
- 小号浅灰说明文字、浅色背景上的白色页脚存在对比度风险；本轮未做 WCAG 仪器化色彩测量，建议上线前补测。
- 本轮使用桌面 Chrome 的精确视口模拟，未覆盖微信内置浏览器、真实 iPhone 安全区和 Android 厂商 WebView。
