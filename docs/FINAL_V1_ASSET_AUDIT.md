## 4. 阻塞项

1. 报告资料页没有最终效果图，也没有可用于页面结构的正式素材；测试版保留现有安全查看结构。
2. 分类素材中大量文字（标题、状态、报告数量）已经烘焙为图片；本轮已获授权使用贴图或留白，真实数据仅用于交互和无障碍语义。
3. 素材目录没有机器可读的动画清单；本轮已获授权在保持设计层级的基础上实现自然过渡。
4. 内置浏览器连接报 `failed to write kernel assets: os error 3`，无法生成实现截图和差异叠加图，最终视觉验收未完成。
