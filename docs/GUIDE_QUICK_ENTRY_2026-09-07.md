# 引导页提前滑动进入

按最新要求取消原来等待最后一张纸落定（2140ms）才解锁的限制。上滑与底部进入按钮在首页预览和路由过渡素材完成解码后即开放，独立于引导页动画进度；装饰纸片还在加载时也可以进入。正常观看时保留原有入场节奏。

快速上滑提交时保留当前引导部件的实际位置、透明度和可见状态。跨路由过渡使用这一帧，暂停内部动画，未加载的装饰图不会随后突然出现。首页整本书和最新公开批次区域仍按原有顺序渐显。短距离、横向和取消的手势维持回弹，重复输入只进入一次。

横屏 WebKit 的缓存图片可能在动态效果偏好确定之前完成加载；初始化之后重新核对已加载的原图，防止就绪回调丢失而停在首帧。

验证：

- `pnpm lint`、`pnpm typecheck`、`pnpm test`、`pnpm prisma:validate`、`pnpm build`。
- 41 个测试文件、274 个测试通过，包括提前滑动、装饰图未加载、目的页未就绪、取消手势、当前帧跨路由保存。
- `pnpm exec node scripts/verify-guide-quick-entry.mjs`：Chromium、WebKit；375×812、430×932、375×667、844×390；另含慢加载装饰图和减少动态效果场景。检查动画结束前即可进入、快照部件坐标/透明度一致、短手势回弹、过渡清理和正常首页落位。结果与截图在忽略目录 `artifacts/guide-quick-entry-qa/`。
- 12 个浏览器场景全部通过。正常竖屏在动画约 748–781ms 时提交上滑，早于原 2140ms 解锁时间；装饰图延迟场景在动画尚未开始时成功进入。跨路由部件位置最大差异约 0.11 CSS px。

本次没有更换设计素材，也不改变加载页标签、首页箭头和标题的浮动频率。
