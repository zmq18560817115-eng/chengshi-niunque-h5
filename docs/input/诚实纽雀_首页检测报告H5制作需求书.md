# **<span style="color: rgb(143,149,158); background-color: inherit">1. 项目目标与交付范围</span>**

本项目用于展示诚实纽雀的检测与溯源信息，帮助消费者快速理解品牌的“透明档案”、检测项目、复核保障及生产溯源内容。供应商需依据已提供的视觉设计稿，完成移动端 H5 页面与可运营的资料管理后台，并协助完成正式环境部署、测试和上线。

| **<span style="color: rgb(143,149,158); background-color: inherit">交付项</span>** | **<span style="color: rgb(143,149,158); background-color: inherit">范围说明</span>** | **<span style="color: rgb(143,149,158); background-color: inherit">验收产物</span>** |
| ------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| **H5 前台**                                                                       | 按设计稿还原单页纵向长页；首页带轻量过场动画；信息模块可点击展开。                                                | 可访问正式链接、前端源代码、部署说明。                                                              |
| **管理后台**                                                                        | 用于上传、编辑、删除检测资料及模块文案；支持预览、发布与下线。                                                  | 后台地址、管理员账号、操作说明。                                                                 |

# **<span style="color: rgb(143,149,158); background-color: inherit">2. 页面信息架构与交互说明</span>**

页面为竖向滚动 H5。图 1 为总体设计稿；图 2 标注了本次需开发的关键区域；图 3 为信息模块展开后的内容样式参考。供应商须以设计源文件为最终切图和尺寸依据，以下描述用于明确功能与交互边界。

## **<span style="color: rgb(222,120,2); background-color: inherit">2.1 首页（图 1 红框）</span>**

**<span style="color: rgb(143,149,158); background-color: inherit">展示内容：</span>**&#x54C1;牌标识、主标题“诚实透明档案”、证件卡片、最新公开批次、检测结论标签及右侧页签等视觉元素。

**<span style="color: rgb(143,149,158); background-color: inherit">过场动画：</span>**&#x9875;面首次打开播放一次，建议总时长 1.5–3 秒：背景/封面渐显 → 标题与证件卡片依次入场 → 检测勾选标签出现 → 落定为可滚动静态首页。纸夹、卡片可采用轻微摆动或浮动效果。

**<span style="color: rgb(143,149,158); background-color: inherit">交互要求：</span>**&#x52A8;画不应阻塞用户滚动或关闭页面；不需要音效；用户再次进入默认不重复强制播放（可按会话或本地缓存控制）。

## **<span style="color: rgb(222,120,2); background-color: inherit">2.2 主要信息模块（图 1 绿框）</span>**

**<span style="color: rgb(143,149,158); background-color: inherit">展示内容：</span>**“检测项目”“复核保障”“生产溯源”等模块按设计稿以标签页/卡片形式呈现，作为页面核心信息入口。

**<span style="color: rgb(143,149,158); background-color: inherit">展开方式：</span>**&#x70B9;击某一模块后，在当前页面展开该模块的详情内容；建议采用向下展开并自动定位到详情首屏，支持收起与切换其他模块。展开、收起需有 200–400ms 的平滑过渡。

**<span style="color: rgb(143,149,158); background-color: inherit">状态规则：</span>**&#x9ED8;认可展示首个重点模块或保持收起，由甲方在联调阶段确认；同一时间建议仅展开一个模块，以减少长页冗余。

## **<span style="color: rgb(222,120,2); background-color: inherit">2.3 展开详情（图 2）</span>**

| **<span style="color: rgb(143,149,158); background-color: inherit">元素</span>** | **<span style="color: rgb(143,149,158); background-color: inherit">需求说明</span>** |
| ------------------------------------------------------------------------------ | -------------------------------------------------------------------------------- |
| **模块标题**                                                                       | 沿用对应色块与标签页风格，例如“检测项目”。                                                           |
| **资料卡片**                                                                       | 每条资料以白色圆角卡片呈现：标题、简述、资料数量/更新时间（可选）及“查看 X 份报告”按钮。                                  |
| **资料查看**                                                                       | 点击按钮打开对应报告列表；支持查看 PDF、图片或外部链接。若同一条目有多份报告，先进入列表或弹层选择。                             |
| **底部提示**                                                                       | 可展示“本页展示最新公开批次结果，如需核对某个批次，可联系客服查询对应批次档案”等运营提示，文案后台可维护。                           |

# **<span style="color: rgb(143,149,158); background-color: inherit">3. 管理后台需求</span>**

后台面向甲方运营人员使用，核心目标是无需改代码即可维护页面资料与文案。后台可为 PC Web 管理界面；首期至少支持 1 类管理员角色，如需多人协作，应提供基础账号管理。

| **<span style="color: rgb(143,149,158); background-color: inherit">功能模块</span>** | **<span style="color: rgb(143,149,158); background-color: inherit">必备能力</span>** |
| -------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| **账号与权限**                                                                        | 管理员登录、退出、修改密码；可选：新增/禁用运营账号并分配维护权限。                                               |
| **信息模块管理**                                                                       | 新增、编辑、删除、排序、上/下线“检测项目 / 复核保障 / 生产溯源”等信息模块。                                       |
| **资料卡片管理**                                                                       | 维护卡片标题、说明、展示顺序、按钮文字、资料数量、底部提示文案。                                                 |
| **资料文件管理**                                                                       | 上传、替换、删除 PDF/图片；填写外链；一张卡片可关联多份资料，并可调整顺序。                                         |
| **内容发布**                                                                         | 保存草稿、预览当前版本、发布到正式 H5、下线内容；发布应有明确的成功/失败反馈。                                        |
| **基础留痕**                                                                         | 至少记录资料最后更新时间和操作人；如实现成本可控，保留发布记录与可回滚上一版本。                                         |



| **<span style="color: rgb(143,149,158); background-color: inherit">文件与内容规则  </span>**&#x9700;与供应商确认单文件大小、支持格式、存储方式及访问权限。若报告包含敏感信息，应支持访问控制或使用甲方提供的受控文件地址。 |
| -------------------------------------------------------------------------------------------------------------------------------------------------------- |



# **<span style="color: rgb(143,149,158); background-color: inherit">4. 技术、兼容与性能要求</span>**

* 前台：移动端优先，基准视觉宽度 375px；适配主流 iOS / Android 手机与微信内置浏览器，兼容常见手机浏览器。

* 页面：HTTPS 访问；首屏优先加载，图片需压缩与按需加载；在 4G 环境下应避免明显白屏。动画使用轻量实现，禁止影响首屏可用性。

* 数据：后台发布内容后可在 H5 生效；所有上传资料须有失效链接检测与异常提示。

* 统计：至少预留页面 PV/UV、模块点击、报告查看按钮点击等埋点接入位置；统计平台由甲方确认。

* 交付：前后端完整源代码、部署文档、接口说明、后台操作手册、第三方服务账号/配置清单。

# **<span style="color: rgb(143,149,158); background-color: inherit">7. 验收标准</span>**

1. 视觉：页面与确认后的设计稿一致，文字、图片、色彩、圆角、层级和模块布局无明显偏差；不同主流手机尺寸不出现错位、截断或遮挡。

2. 交互：首页过场动画正常、可跳过/不阻塞浏览；信息模块可正常展开、收起、切换；报告入口能准确打开对应资料。

3) 后台：可独立完成模块、卡片、文案和资料的新增、编辑、删除、排序、预览、发布/下线；发布后前台展示正确。

4) 稳定性：主流微信环境可正常打开和滚动；无阻断性报错、死链、无法上传或无法发布的问题。

5. 交付：源代码、部署说明、后台使用说明、管理员权限和相关配置均已完整移交。

# **<span style="color: rgb(143,149,158); background-color: inherit">8. 需在启动会确认的事项</span>**

* 设计源文件是否完整交付；首页动画是否需要甲方提供动效参考或由供应商先出分镜。

* 展开详情为页面内展开、弹层，还是新页面；报告查看采用在线预览、下载还是跳转外链。

* 首期模块数量、每模块的资料卡片数量、每条资料的最大文件体积及文件格式。

* 域名/服务器/对象存储/备案是否已具备；若未具备，供应商报价是否包含代部署与环境配置。

* 上线后维护期限、缺陷响应等级、是否包含埋点平台接入和数据看板。
