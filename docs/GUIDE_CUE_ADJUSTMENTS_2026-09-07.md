# 引导提示与首页点击箭头调整

- 引导文字图片解码后即可显示，不再因素材整体加载或进入按钮尚未解锁而隐藏。提示自身的轻微浮动与引导动画同时启动；进入按钮和滑动切换沿用既有时间与交互条件。
- 第二个“点击”箭头下移 24 母版像素，即 750px 设计稿的 9px（375px 屏宽约 4.5px）。箭头图片与点击区域读取同一份修正坐标；三个箭头到标题的间距分别约 6.94 / 6.94 / 7.69 CSS px（375px 屏宽）。
- 三个箭头的浮动幅度由自身高度的 9% 改为 24%，375px 屏宽约由 3.7px 增至 9.9px。周期仍为 1800ms。标题逐字动画和鱼部件的节奏未更改。
- WebKit 实测发现缓存图片的解码回调可能先于被动 effect 执行，随后清理会丢失已经就绪的图层。就绪集合初始化改到 layout effect，使初始化早于解码回调，避免停留在首帧。
- 原图及 `docs/input/` 保持原样；调整只作用于显示样式、共享坐标和初始化时机。

验证脚本：`pnpm exec node scripts/verify-guide-cues.mjs`。使用 Chromium 与 WebKit 的 375×812、430×932、375×667 视口，检查慢加载中的提示、进入按钮解锁前的提示动画、首页箭头幅度与间距、第二箭头跳转及减少动态效果设置。截图与测量结果存放于忽略目录 `artifacts/guide-cues-qa/`。
