## 用户截图反馈修正

- 模块一取消书本／批次的横向背景切片，改为一张连续底图和透明批次文字，入场仅移动透明部件，不露出横向断层。缺少独立黄色底层的处理见 `OPEN_QUESTIONS.md` 第 23 项。
- 模块二改为八个独立原图部件，按实际叠放关系显示。文件夹按压仅调整其素材亮度，取消整块缩放、矩形底色和矩形边框反馈。
- 三块文件夹点击区域来自原始 alpha 轮廓，扣除上层文件夹、纸张和人物的遮挡，覆盖可见彩色板块。移除跨越黄绿边界的人物矩形热区，三个“点击”提示继续进入各自分类。
- 文字动画始终只作用于七个透明字图，结束时不再卸载覆盖层或切换整块文字区域底图，横线与星星保持可见、位置不变。
- 小鱼此前只抽取了纵向质心位移，并把整段 8640ms 当成一次缓慢移动，丢失了原图明显的交替倾斜。现从原 GIF 的鱼形主轴恢复四条鱼各自的旋转和位移，复用 `--archive-click-cue-duration`，气泡和肌理不参与动画。可用 `scripts/refresh-design-assets.py --fish-motion` 单独重新生成，无需重建其余图片。

## 生成与验证

`scripts/refresh-design-assets.py --source <素材目录>` 建立原始清单和配准数据，`--build` 生成运行时资产和配置。Python 依赖为 Pillow、NumPy、OpenCV；配准歧义与缺失部件处理见 `OPEN_QUESTIONS.md` 第 23–25 项。WebP 仅做裁切、缩放与源部件合成，不使用生成式补图。

仓库门禁：`pnpm lint`、`pnpm typecheck`、`pnpm test`、`pnpm prisma:validate`、`pnpm build`。

浏览器验收：`pnpm exec node scripts/verify-asset-refresh.mjs`，默认本地 3000 端口，可通过 `H5_QA_URL` 指向本地生产构建。覆盖 375×812、390×844、428×926、320×568、844×390 五种尺寸，截图及结果写入 `artifacts/asset-refresh/browser/`；检查破图、横向溢出、旧素材请求、15 个独立标题部件、3 个箭头、实际动画频率和三条完整报告访问链路。
