# 加载页人物标签移动恢复

加载过渡此前只渲染 `loading-poster.webp`，人物标签与加载条均为静态。现在使用当前素材包的独立人物，恢复沿加载条从左向右移动及白色填充跟随。旧版本 GIF 为 45 帧、每帧 80ms，共 3600ms；本次沿用 3600ms 循环，以 CSS 平移和缩放实现。

背景、文字和黄色条保持固定。派生底图只在原人物区域使用同包的“背景纹理.png”补回底纹，再放回同包黄色条；没有修改设计输入或绘制新人物。两个新增 WebP 合计约 98KB。可用 `python scripts/refresh-design-assets.py --loading-motion` 重建，完整 `--build` 也包含这一生成步骤。

首页进入分类页使用提前挂载的加载层：隐藏期间暂停，显示时开始循环。分类页打开报告使用普通加载层：素材就绪后开始循环。图片失败或减少动态效果时保留完整静态画面。素材就绪判断兼容图片在页面水合前已经加载完毕的情况。页面就绪仍立即交接，不为播放动画延长等待。

浏览器验证：`pnpm exec node scripts/verify-loading-motion.mjs`，覆盖 Chromium / WebKit、375×812、375×667、430×932、844×390，以及两种过渡、素材失败与减少动态效果。证据写入忽略目录 `artifacts/loading-motion-qa/`。

本次验证结果：14 项浏览器场景通过；标签与填充前沿在起点、中点和末端保持对齐，短屏、长屏及横屏均无标签裁切。五项必需检查通过，41 个测试文件 / 272 项测试通过。
